# Context Window — 节拍表

150 bpm，1 拍 = 0.4 秒，1 小节 = 1.6 秒。时间来自 `data/lyrics.json` 和 `data/sections.json`。视觉值见 `STYLE.md`：底 `#0A0A0B`，骨白 `#EEE9DF`，信号色洋红 `#FF2E88`，歌词用 Unbounded。

**贯穿全片的线索：光标**，作用相当于原作的火花。一个闪烁的洋红块状光标 `▌`，每个场景都由它"写出来"，最后回到空白画面里一个闪烁的光标，和开头首尾相接。

**贯穿全片的数字：token 计数器**，放在右上角，用 Plex Mono。数值只增不减，直到溢出：0 → 200,000 → 1,000,000 → `OVERFLOW` → `NaN` → 0。

**歌词规则**：唱到哪个词，哪个词从骨白变成洋红。口吃音节 `C-` 每次都触发一次硬切或一次缩放冲击。

|---|---|---|---|---|
| 1 | 0.0–3.6 | Intro | **boot**：黑屏中一个光标闪烁，键盘声每响一次，就逐字打出 `system:` | 硬切（卡在第一句歌词上） |
| 2 | 3.6–14.6 | Intro | **system**：巨大的衬线斜体 "You are a helpful assistant!"。"helpful" 重复时开始口吃、错位，复制出 3 层 | 文字折叠成一行，被推到画面顶端，成为第一条消息 |

| 4 | 27.4–32.2 | Pre-Chorus 1 | **scroll**：对话无限向下滚动，速度随 "scroll" 加速，每唱一次 scroll 就冲一下。"long long long" 时文本被拉长成竖条 | 竖条收拢成一个光标，然后爆开成满屏洋红 |
| 5 | 32.2–49.8 | Chorus 1 | **hook1**：满屏洋红，黑色 Unbounded 字。`C-C-CONTEXT!` 逐个音节切换，"(window!)" 时画面缩成一个窗口框。"Token×4" 时计数器占满画面，"Two hundred K" 时计数到 200,000。只有极轻微的故障效果 | 窗口框缩小，退回界面，露出下面的缓存 |

| 9 | 75.4–78.2 | Bridge | **compress**：整段对话历史像被液压机压扁，每喊一次 "Compress!" 压一次，从 3 屏压成 1 屏，再压成一行 | 压扁的一行展开成列表 |
| 10 | 78.2–84.7 | Bridge | **bullet list**：一张用线条画的人脸（骨白描线）逐笔拆解成要点列表，"Your voice" 时一条声波被拉平成一条直线 | 镜头推进到剩下的唯一一行 |
| 11 | 84.7–88.2 | Bridge | **oracle**：全屏黑底，Cormorant 斜体只写一行 "User was kind."，全片最安静的 4 秒，没有故障、没有计数器 | 计数器突然回到画面，跳成 `1,048,575`（2²⁰ − 1） |
| 12 | 88.2–99.4 | Break | **overflow**：计数器数字超出位数，挤破画框，文字从窗口边缘溢出并层层堆叠；"O-O-O" 时画面三次故障重复；"Error: maximum length" 用红框报错对话框，全片唯一的系统对话框 | 对话框被点掉，画面全黑 |
| 13 | 99.4–113.8 | Drop | **keystorm**：只有键盘声和人声切片。黑底上用 Plex Mono 字符组成一片"键盘雨"，每一声 click 落一排字符，字符越积越多，堆成一个由 token 组成的地形，镜头从上空俯冲下去。最后 1 小节全屏闪 4 次洋红 | 在 113.8 秒的重拍上硬切到满屏洋红 |
| 14 | 113.8–130.6 | Final Chorus | **hook3**：最强的一次。满屏洋红，前面所有场景的碎片（图钉、格子、要点列表、报错框）按节拍快切闪回。计数器从 1,000,000 → `∞` → `NaN`。"Where did we begin?" 时所有东西向画面中心坍缩 | 坍缩成一个点 |
| 15 | 130.6–133.0 | Final Chorus 尾 | **where did we—**：一片空白，只剩句子被截断在 "we—"，在破折号后面放一个光标 | "New chat!" 时硬切 |

## 镜头运动

- **界面段**（3、4、7、16）：2D 平移和滚动。滚动速度用弹簧曲线，卡在节拍上冲一下。
- **3D 段**（6、13）：three.js 透视相机做慢推和俯冲，景深要浅。
- **hook 段**（5、8、14）：相机固定不动，只用缩放冲击（每个 `C-` 放大约 1.06 倍，然后迅速回落）和硬切。
- **Bridge**（9–11）：全片节奏最慢的地方，没有相机运动，只有压缩的动作，最后完全静止。

## 与原仓库的对应

| 原作做法 | 本片用在哪里 |
|---|---|
| `prompt` 场景，用参数复用 | 第 3、7、16 场，共用一个对话界面模块 |
| `hook` 场景，用参数复用 | 第 5、8、14 场，共用一个模块，用一个"损坏程度"参数（0 / 0.4 / 1）控制差异 |
| 火花贯穿全片 | 光标 |
| P(doom) 数值上涨 | token 计数器 |
| 光线步进地形 | 第 13 场的 token 地形 |
| opentype.js 生成文字几何 | 第 9 场的压缩、第 12 场的溢出、第 13 场的字符雨 |
| 后期处理 | 全片统一加 bloom、halation 和颗粒；hook 段再加 RGB 通道错位 |
