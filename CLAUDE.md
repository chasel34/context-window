# CLAUDE.md

Code-rendered lyric MV for the song "Context Window". Renderer adapted from mexicat/pdoom-video (MIT).

## Commands (in `app/`)

- `bun run dev` — preview at :5173 (`?t=32.5`, `?scene=s05&loop`, `?only=s05`)
- `bun run typecheck` — run before finishing any change
- `bun run build` — static build to `app/dist` (deployed to GitHub Pages by `.github/workflows/pages.yml`)
- `bun run render --scene s05 --preview` — render one scene; `bun scripts/render.ts sheet --scene s05 --n 12 --out ../out/wip/sheet.png` for a contact sheet to inspect

## Layout

- `app/src/timeline.ts` — the 16 scene windows, anchored to lyrics/sections/beat grid (never hand-typed floats)
- `app/src/scenes/sNN_*.ts` — one scene per file; `app/src/shared/` — modules scenes share; `app/src/engine/` — core
- `data/*.json` — generated by `analysis/` (uv); treat as read-only input
- `docs/` — BEATSHEET (what each scene shows), STYLE (palette/fonts), ENGINE (scene API — read before writing a scene)

## Rules

- Every frame is a pure function of song time `t`: no `Math.random()`, `Date.now()`, `performance.now()`. Use `mulberry32`/`hash` from `engine/util.ts`; seed per-frame flicker with `frameIdx(t)`.
- No state between `render()` calls unless the scene sets `stateful = true` and resets in `reset()`.
- Keep frames under ~25 ms; precompute in `init()`.
- Find lyrics by content (`lyrics.get('...')`, `tl.wordTimes(...)`), never hard-code times.
- One signal colour (`#FF2E88`) for the whole film.
- Files adapted from pdoom-video keep their header comment.
- `out/`, `reference/`, `source-repo/`, the WAV and stems are local only (gitignored).
